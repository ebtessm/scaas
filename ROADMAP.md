# Roadmap (proposed) / خطة مقترحة

These are proposals for discussion, not commitments. / مقترحات للنقاش وليست التزامات.

| Phase | Goal | الهدف |
|---|---|---|
| 0 | Document the idea and diagram (this repo) | توثيق الفكرة والرسم |
| 1 | Define a component metadata format (name, signature, concept tags, license) | تعريف صيغة وصف المكوّن |
| 2 | Small prototype: add a component, index it by signature and keywords, search it | نموذج أولي صغير: إضافة وفهرسة وبحث |
| 3 | Publish road-safety risk scoring as the first reusable component | نشر تقييم مخاطر الطرق كأول مكوّن |
| 4 | Add semantic search and quality checks | بحث دلالي وفحص جودة |
| 5 | Study hosting on a national cloud with security and legal review | دراسة الاستضافة على سحابة وطنية بمراجعة أمنية وقانونية |

Open questions: who operates the cloud, data protection rules, licensing of shared components, and review by domain experts.
